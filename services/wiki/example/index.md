# Example Wiki

A minimal, game-neutral content directory built with the otomo wiki framework.
Copy this directory, edit `_site.yml`, and add Markdown pages.

- [Getting started](guide/getting-started.md) — preview the site and understand
  the layout.
- [Writing pages](guide/writing-pages.md) — the content contract in one page.

The framework owns the theme, navigation, search, Markdown extensions and the
strict build. A content directory only supplies `_site.yml`, Markdown pages and
`assets/`.
